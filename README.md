## What the Project Does
- Fetches 1 year of daily stock data for SpaceX competitors:
  - Lockheed Martin (LMT)
  - Northrop Grumman (NOC)
  - Boeing (BA)
  - Raytheon (RTX)
- Calculates **50‑day and 200‑day moving averages**
- Plots the closing price with both moving averages
- Saves charts automatically in the `charts/` folder

## Why It Matters
Moving averages are one of the most basic yet powerful tools in finance.  
They help smooth out price data and reveal long‑term trends.  
For me, this project is less about trading and more about learning how to:
- Pull real‑world data
- Process it with Python
- Visualize it clearly
- Document and share it professionally
